# Whetstone Help Centre

Plain-language guides to using Whetstone. No technical knowledge needed.

**Whetstone connects business owners with semi-retired and retired professionals
for short, paid, clearly-defined advisory sessions.** Every advisor is checked by
a real person before they can take work, every session is covered by insurance,
and your money is held safely until the work is done.

### A note on money and time in these guides

- **Prices** shown are examples in Australian dollars (AUD). Whetstone works in
  several currencies — you'll always see the currency symbol next to a price.
- **Times** are always shown in one consistent time zone across the whole site,
  so a time you see on a booking is the same time your advisor sees.
